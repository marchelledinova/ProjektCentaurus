01 / features

Everything a dropdown needs, nothing it doesn't

Open, close, search, choose and style. Each piece is small enough to read in one sitting.

Behavior

  • Open and close with a click, or call open() and close() from code
  • Click outside or press Esc to close the menu
  • Many instances on one page, each with its own options
  • Searchable lists that filter as you type
  • Selectable mode where the button shows your choice
  • Dividers to group related items

Keyboard & access

  • Arrow keys move through options and wrap around
  • Home / End jump to the first or last option
  • Enter or Space chooses the highlighted option
  • Esc closes and returns focus to the button
  • Screen readers get roles, aria-expanded and active-item hints
  • Closed menus are removed from the Tab order

Look & feel

  • CSS variables for accent, background, text, border and radius
  • setStyle() changes colours while the page is running
  • Smooth motion that switches off for reduced-motion users
  • Responsive menus that slide back on screen or open upward
  • Variants such as a ghost nav button and a wide select
  • Custom buttons with your own HTML, like an avatar

03 / how it works

One class, four small jobs

DropJS turns a plain element into a button and a menu, listens for events, and keeps the menu on screen.

  • _bind()listens for clicks, keys and outside clicks

04 / quick start

Up and running in three steps

No build tools, no install. Copy two files next to your page.

  1. Add the files

    Link style.css and dropjs.js in your page.

  2. Add an empty element

    DropJS builds the button and menu inside it.

  3. Create the dropdown

    Pass your options. Call open() and close() whenever you like.

index.html
<link rel="stylesheet" href="style.css">

<div id="dropdown"></div>

<script src="dropjs.js"></script>
<script>
  const menu = new DropJS({
    target: "#dropdown",
    label: "Menu",
    options: [
      { label: "Home", value: "home" },
      { label: "Settings", value: "settings" },
      { label: "Profile", value: "profile" }
    ]
  });

  menu.open();
  menu.close();
</script>
