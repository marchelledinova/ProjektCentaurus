DropJS

Dropdowns without the dependencies.

DropJS is a small prototype menu library in plain HTML, CSS and JavaScript. Every dropdown on this page, including the two in the header, comes from one new DropJS() call.

Quick start

Point DropJS at an empty element and pass your options. It builds the button and the menu for you.

const menu = new DropJS({
  target: "#dropdown",
  label: "Menu",
  options: [
    { label: "Home", value: "home" },
    { label: "Settings", value: "settings" },
    { label: "Profile", value: "profile" }
  ],
  onSelect: (option) => notify(option.label)
});

menu.open();
menu.close();

Keyboard: Enter or ↓ opens the menu, ↑ ↓ move, Enter selects, Esc closes.

Searchable dropdown

Add searchable: true. Type to filter the list, then press Enter to pick the first match. The button shows your choice.

new DropJS({
  target: "#country-dropdown",
  label: "Choose a country",
  searchable: true,
  placeholder: "Search countries",
  emptyText: "No countries match",
  options: countries
});

Customization

The style option sets CSS variables: accent, bg, text, muted, border and radius. Change them any time with setStyle(). 

const themed = new DropJS({
  target: "#themed",
  label: "Sort by",
  selectable: true,
  style: { bg: "#16213e", text: "#eef1fb", accent: "#8ab4ff" },
  options: [ ... ]
});

themed.setStyle({ accent: "#d6336c", bg: "#fff7f8" });
